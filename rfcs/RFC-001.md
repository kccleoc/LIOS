# RFC-001: LIOS v2.0 Architecture Upgrade

## Summary
Reorganize LIOS repository from flat prompt-driven structure into a modular, agent-native architecture. No investment philosophy changes.

## Motivation
The prompt-driven model (paste lios/v1.X.md → AI memory → response) creates opaque state. The new model (Git repository → versioned knowledge → agent → execution) makes the repository the permanent source of truth, with AI agents as interchangeable execution engines.

## Proposed Change
Reorganize into: constitution/, core/, portfolio/, research/, scores/, playbooks/, workspace/, templates/, rfcs/, decisions/, archive/. Create VERSION.md, LICENSE. Extract all component content into modular files. Maintain backward compatibility with paste-ready workflow.

## Impact
- Constitution: Unchanged (L1-L18 preserved verbatim)
- Core: Extracted into modular files (no rule changes)
- Portfolio: Structured data files added
- Commands: All 27 commands remain valid at original paths
- New: VERSION.md, LICENSE, workspace/, templates/, playbooks/

## Alternatives Considered
1. Incremental refactor within existing structure — rejected: doesn't achieve agent-native goals
2. Stay on v1.5 indefinitely — rejected: prompt-driven model limits agent autonomy
